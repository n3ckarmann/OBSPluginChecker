**New languages:** The Plugin Checker now follows the OBS language and is available in English, German, Spanish, French, Italian, Portuguese, Polish, Dutch, Japanese, Korean and Simplified Chinese. Other languages fall back to English.

**Neue Sprachen:** Der Plugin-Checker folgt jetzt der OBS-Sprache und ist auf Englisch, Deutsch, Spanisch, Französisch, Italienisch, Portugiesisch, Polnisch, Niederländisch, Japanisch, Koreanisch und vereinfachtem Chinesisch verfügbar. Andere Sprachen erscheinen auf Englisch.

**Downloads**
- Windows x64: `obs-plugin-checker-0.1.1-windows-x64.zip`
- macOS (Apple Silicon + Intel): `.pkg` or `.zip`. Not signed by Apple; if macOS blocks it, see the [README](https://github.com/n3ckarmann/OBSPluginChecker#macos-plugin-is-blocked).
- Linux (Ubuntu 24.04, x86_64): `.tar.xz`
- Checksums: `SHA256SUMS.txt`
