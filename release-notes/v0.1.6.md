**Clean up old backups**

- Every update and removal keeps the old files and a restore script. Under "Files…" of the Plugin Checker's own entry there is now "Clean up backups…": it lists all backups with plugin, date and size, can select all but the newest per plugin, and deletes them after you confirm. Backups that still wait for OBS to exit are never offered for deletion. Closes [#6](https://github.com/n3ckarmann/OBSPluginChecker/issues/6).

**Table always fills the window**

- The plugin table now always spans the full window width. The last column stays attached to the right edge; dragging a column divider only shifts width between the columns, and resizing the window scales them proportionally. Closes [#7](https://github.com/n3ckarmann/OBSPluginChecker/issues/7).

**Alte Backups aufräumen**

- Jedes Update und jede Entfernung behält die alten Dateien und ein Skript zum Wiederherstellen. Unter „Dateien…“ beim Eintrag des Plugin-Checkers selbst gibt es jetzt „Backups aufräumen…“: Es zeigt alle Backups mit Plugin, Datum und Größe, kann alle bis auf das neueste je Plugin auswählen und löscht sie erst nach deiner Bestätigung. Backups, die noch auf das Beenden von OBS warten, werden nie zum Löschen angeboten. Erledigt [#6](https://github.com/n3ckarmann/OBSPluginChecker/issues/6).

**Tabelle füllt immer das Fenster**

- Die Plugin-Tabelle ist jetzt immer so breit wie das Fenster. Die letzte Spalte bleibt am rechten Rand; beim Ziehen einer Spaltengrenze wird die Breite nur zwischen den Spalten verschoben, und beim Ändern der Fenstergröße wachsen oder schrumpfen sie anteilig. Erledigt [#7](https://github.com/n3ckarmann/OBSPluginChecker/issues/7).

**Downloads:** Windows installer `.exe` and `.zip`, macOS `.pkg`/`.zip` (unsigned, see the [README](https://github.com/n3ckarmann/OBSPluginChecker#macos-plugin-is-blocked)), Linux `.tar.xz`, checksums in `SHA256SUMS.txt`. The Plugin Checker needs OBS 31.1 or newer.
