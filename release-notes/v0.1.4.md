**The Plugin Checker checks itself**

- The Plugin Checker now appears in its own list, marked "(this plugin)", and can update itself with "Update…" like any other plugin. When a newer version is out, the header shows a note with a link to the release. It still cannot remove itself: use the uninstaller or delete its files after closing OBS. Closes [#4](https://github.com/n3ckarmann/OBSPluginChecker/issues/4).

**Der Plugin-Checker prüft sich selbst**

- Der Plugin-Checker erscheint jetzt in seiner eigenen Liste, markiert mit „(dieses Plugin)“, und kann sich mit „Aktualisieren…“ selbst aktualisieren wie jedes andere Plugin. Gibt es eine neuere Version, zeigt die Kopfzeile einen Hinweis mit Link zum Release. Entfernen kann er sich weiterhin nicht selbst: Nutze den Deinstaller oder lösche seine Dateien, nachdem OBS beendet ist. Erledigt [#4](https://github.com/n3ckarmann/OBSPluginChecker/issues/4).

**Downloads:** Windows installer `.exe` and `.zip`, macOS `.pkg`/`.zip` (unsigned, see the [README](https://github.com/n3ckarmann/OBSPluginChecker#macos-plugin-is-blocked)), Linux `.tar.xz`, checksums in `SHA256SUMS.txt`. The Plugin Checker needs OBS 31.1 or newer.
