**Plugins without a version number**

- Windows: the installed version is now also read from plugins that ship without a version resource, e.g. Source Profiler.
- Plugins whose version cannot be read at all (e.g. Scale to Sound, Waveform) can still be updated: "Update…" and "Download" are no longer greyed out. The hint explains that you decide whether the latest release is newer. Fixes [#2](https://github.com/n3ckarmann/OBSPluginChecker/issues/2).
- No more duplicate release drafts when a release is published (maintenance). Fixes [#3](https://github.com/n3ckarmann/OBSPluginChecker/issues/3).

**Plugins ohne Versionsnummer**

- Windows: Die installierte Version wird jetzt auch bei Plugins erkannt, die keine Versionsinfo in der DLL mitbringen, z. B. Source Profiler.
- Plugins, deren Version sich gar nicht auslesen lässt (z. B. Scale to Sound, Waveform), kannst du trotzdem aktualisieren: „Aktualisieren…“ und „Download“ sind nicht mehr ausgegraut. Der Hinweis erklärt, dass du selbst entscheidest, ob das neueste Release neuer ist. Behebt [#2](https://github.com/n3ckarmann/OBSPluginChecker/issues/2).
- Beim Veröffentlichen entsteht kein doppelter Release-Entwurf mehr (Wartung). Behebt [#3](https://github.com/n3ckarmann/OBSPluginChecker/issues/3).

**Downloads:** Windows installer `.exe` and `.zip`, macOS `.pkg`/`.zip` (unsigned, see the [README](https://github.com/n3ckarmann/OBSPluginChecker#macos-plugin-is-blocked)), Linux `.tar.xz`, checksums in `SHA256SUMS.txt`. The Plugin Checker needs OBS 31.1 or newer.
