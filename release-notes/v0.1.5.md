**A more flexible window**

- All columns can be resized, and a divider between the list and the details can be dragged, so the whole list fits without scrolling. Window size, column widths and the divider are remembered. Closes [#5](https://github.com/n3ckarmann/OBSPluginChecker/issues/5).

**Ein flexibleres Fenster**

- Alle Spalten lassen sich in der Breite ziehen, und zwischen Liste und Details gibt es einen verschiebbaren Trenner, damit die ganze Liste ohne Scrollen passt. Fenstergröße, Spaltenbreiten und Trenner werden gespeichert. Erledigt [#5](https://github.com/n3ckarmann/OBSPluginChecker/issues/5).

**Downloads:** Windows installer `.exe` and `.zip`, macOS `.pkg`/`.zip` (unsigned, see the [README](https://github.com/n3ckarmann/OBSPluginChecker#macos-plugin-is-blocked)), Linux `.tar.xz`, checksums in `SHA256SUMS.txt`. The Plugin Checker needs OBS 31.1 or newer.
